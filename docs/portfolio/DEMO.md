# 关键页面与演示脚本

## 建议演示顺序（5 分钟）

### 0:00–0:30｜问题与定位

打开 [案例页](../index.html)，说明：

> 这个项目不尝试让大模型“预测涨跌”，而是解决每日投研中数据分散、长任务不可见、模型缺乏最新依据这三个问题。

### 0:30–1:30｜全市场流程

打开榜单首页：

1. 指出最上方市场状态栏：主状态以上证为准，四个指数显示各自状态；
2. 点击“执行全市场流程”；
3. 展示阶段、百分比、当前动作；
4. 解释增量更新与 15:35 数据就绪口径；
5. 展示异常时的“带警告完成”，强调异常股票被排除但整批结果保留。

建议话术：

> 长任务最危险的不是慢，而是不知道它在做什么。这里把进度、异常和最终状态都变成产品协议，而不是后端日志。

### 1:30–2:30｜基本面榜与市场结构

先展示排在最前的基本面价值榜，再切换四份技术榜单，说明：

- 基本面榜不使用均线、动量或突破决定入选；
- “未来空间”来自行业景气、财报收入份额、业绩预告和机构预测，不是大模型主观打分；
- 高风险硬剔除，低风险仍会标注“不等于无风险”；
- 关键前瞻数据缺失的股票不入榜，并显示置信度；
- 榜单是研究候选，不是买入信号；
- 市场涨跌家数使用完整行情截面，不用筛选后股票池冒充；
- 生产权重与候选因子研究隔离。

### 2:30–3:10｜新闻与每日总结

打开新闻页和每日总结：

- 新闻保留原标题、来源、时间和链接，不让模型二次改写标题；
- 日报读取当日行情、指数、榜单和新闻；
- Markdown 在前端渲染为可读结构；
- DeepSeek 失败时保留核心榜单。

### 3:10–4:20｜联网数据问答

在问答页选择“智能触发”，输入：

> 今天市场上涨家数为什么明显增加？结合最新政策和平台数据回答，并列出依据。

观察：

1. “正在联网检索”状态；
2. SSE 逐字输出；
3. 回答后的来源链接；
4. 搜索失败时的 RSS / 本地数据降级提示。

再问一个稳定问题：

> RSRS 因子在这个项目里起什么作用？

说明智能模式不会为稳定知识浪费搜索额度。

### 4:20–5:00｜失败实验与复盘

打开 [失败实验与迭代复盘](RETROSPECTIVE.md)：

> 我尝试过替换趋势因子，但训练或验证指标没有过门禁，所以拒绝上线。对 AI 产品经理而言，比“做了一个功能”更重要的是知道何时不发布，以及下一轮需要补什么数据。
